Interactive Architecture

Seamless overlap without jarring layout shifts.

By synchronizing GPU-accelerated CSS transforms with high-frequency scroll telemetry via requestAnimationFrame, the animation achieves 60fps fluidity across desktop and mobile devices.

01

Sticky Scroll Runway

The hero track is given an extended height (e.g. 180vh), while the inner viewport container is pinned with position: sticky. This converts vertical scroll distance into a normalized progress ratio from 0.0 to 1.0.

02

requestAnimationFrame Sync

Scroll events only schedule an animation tick rather than directly updating DOM nodes. This eliminates scroll hitching and guarantees transform updates align with browser paint cycles.

03

Spatial Depth & Overlap

As the hero recedes into the background (scaling down from 1.0 to 0.86), the content container slides in front with rounded corners and a soft shadow, completing the layered physical depth illusion.
